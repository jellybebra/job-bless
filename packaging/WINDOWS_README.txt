job-bless для Windows x64

Установка: запустите job-bless-Setup.exe и нажмите «Установить и открыть».
В переносном ZIP: распакуйте архив и откройте Start-job-bless.vbs.

Python, Node.js, AIStudioToAPI и Camoufox уже входят в комплект.
При первом подключении нейросети ничего скачивать не нужно.
Для HH нужен запущенный Docker Desktop с Linux-контейнерами.
При первом запуске job-bless сам собирает контейнер Camoufox (нужен интернет);
затем использует готовый образ. Вход в HH открывается внутри панели.
При переходе со старой версии войдите в HH заново.

В разделе «Действия» нажмите «Подключить Google AI Studio» и войдите
в Google в открывшемся окне. Завершите все шаги, которые предложит Google.
После входа приложение проверит модель и сохранит подключение.
Интернет нужен для входа, генерации ответов и работы с hh.ru.

Ваши данные хранятся отдельно: %LOCALAPPDATA%\job-bless\data.
Журнал запуска: %LOCALAPPDATA%\job-bless\job-bless.log.
Обновление программы не удаляет базу данных и сохранённые входы.
Повторный запуск открывает уже работающее приложение.
Чтобы завершить работу, нажмите «Завершить работу» в меню приложения.
Приложение сохранит сессию и остановит свой контейнер HH.

В комплекте есть AIStudioToAPI под лицензией CC BY-NC 4.0
(для некоммерческого использования). Подробности: THIRD_PARTY_NOTICES.md.
